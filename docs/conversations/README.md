# Working conversations

Raw exports of the Claude Code conversations used to plan and run this project, kept for
traceability. They are long and unedited; the distilled version is `../journal.md`.

To add one, run `/export` inside the conversation, save the file here with a dated name
(for example `2026-10-14_planning.txt`), and commit it.

These exports are working notes, not results: when they disagree with the `RAPPORT*.md`
files or with `journal.md`, the latter are authoritative.
